# FakeTube

Paródia do YouTube em Expo.

## Começando

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o app:

   ```bash
   npx expo start
   ```

Este projeto é uma reprodução de interface e experiência de visualização de vídeos em estilo de um clone de YouTube, criada com Expo e React Native.
